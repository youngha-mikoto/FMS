# 개별연구(CSC 현장실습-모바일 로봇 인공지능 기술 개발)

목표:

- 프로젝트 페이지에 소개된 "SMART-LLM"과 "LaMMA-P" 코드를 직접 실행해보고, 그 내용을 분석한 후 보완하는 것을 목표

- SMART-LLM: https://sites.google.com/view/smart-llm/

- LaMMA-P: https://lamma-p.github.io/

내용:

1. iTHOR(AI2-THOR) 시뮬레이터 활용 다중 로봇 작업 수행 테스트

-> https://ai2thor.allenai.org

2. SMART-LLM 기반 다중로봇 작업 할당 기술 개발

-> LaMMA-P 공개 코드 설치 및 실행

-> 또는 비슷한 기능을 직접 구현 (프롬프트엔지니어링)

3. LaMMA-P 기반 다중로봇 작업 할당 기술 개발

-> LaMMA-P 공개 코드 설치 및 실행

-> 또는 비슷한 기능을 직접 구현 (프롬프트엔지니어링)

4. SMART-LLM 및 LaMMA-P 구현 내용 최종 발표 (성능 비교 실험)

일정:

- 중간 발표(11/6): 1-2번 수행 결과 발표

- 최종 발표(12/18): 3-4번 수행 결과 발표
